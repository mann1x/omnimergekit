# CD mix maps — Qwen3.6 / Ornith 35B-A3B (40 layers)

`--tensor-type-file` maps for the ContribDynamic **mix** tiers of the
Qwen3.6-family MoE (`num_layers: 40`, tensors span `blk.0`..`blk.39`),
generated by `scripts/generate_cd_maps_mix.py --out-dir <this dir>` from
imatrix `3a116ed118b19cd1…` on 2026-07-15.

**These are model-specific. Do not put them in bare `scripts/`.**
The classic-named `scripts/tensor_types_CD-*.txt` on `main` are the
**Gemma-4 26B-A4B** maps (`num_layers: 30`, `blk.0`..`blk.29`, imatrix
`dc2a5e35cd686b0f…`). The two sets use identical filenames, so writing
either into a shared directory silently overwrites the other and neither
copy is self-identifying at the path level — the `.meta.json` sidecar is
the only thing that distinguishes them. Always generate into a
per-model `cd_maps_*` directory.

Tier suffixes: `_L` body-weighted (low tier at the file base ftype),
`_h` head-weighted. `file_base.json` maps each recipe name to the
`-q <FTYPE>` argument llama-quantize requires; `build_eval_mix_cdiq.sh`
FATALs if it is missing.
